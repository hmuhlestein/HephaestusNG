Summary

Requirements analysis found that the direct OpenRouter cost-capture mechanism — intercepting orchestrator LLM calls, extracting token/cost usage, and writing CostEntry rows — was already built by earlier features on this branch. This feature's actual scope narrowed to closing the two gaps that analysis found: no test coverage of the extraction logic, and an over-broad exception handler that logged real bugs at debug level (invisible by default).
