This feature wires four already-built cost display components — built but never imported by the sibling Budget Enforcement feature — into three live screens, and adds one additive backend field. No new cost computation, schema, or enforcement logic was added.

Summary

The design document's UI scope called for a budget indicator on the autopilot pipeline screen linking to ProjectSettingsModal, surfacing cost_total_usd on feature cards, and distinguishing paused_by == "budget" from "user" in the UI. All three were found unwired or missing a supporting backend field, despite the underlying components and endpoints already existing from the merged Budget Enforcement feature. This feature closes that visibility gap.
