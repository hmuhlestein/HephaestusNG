Key Implementation Details

  • Two enforcement points: pick_next_design() skips over-budget projects when picking the next queued design; _run_one_feature() blocks new workflow launches (returns "budget_blocked") for an over-budget project
  • Self-heal exclusion: _try_auto_resume_paused_workflow, _create_corrective_task, and stuck-workflow restart all now skip any workflow with paused_by is not None — a deliberate pause of any kind ("user", "budget", "system") is respected, not just user pauses
  • Play-button exception preserved: AutopilotService.start() deliberately keeps == "user" so clicking play resumes user-paused work but never auto-resumes budget-paused work
  • Phase 0 coverage: /autopilot/stop now shares _pause_project_workflows, which matches both "autopilot" and "autopilot-phase0" definition IDs — closing a gap where Phase 0 workflows kept running through a stop/budget-pause
  • Limit-raise resume: raising or clearing cost_limit_usd via PUT /projects/{id} clears paused_by == "budget" on that project's workflows
