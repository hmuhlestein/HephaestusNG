Key Implementation Details

  • Append-Only Ledger: cost_entries table is source of truth; denormalized rollups derived on write, self-healed on read
  • Self-Healing: derive_*_cost() functions recompute from ledger and correct mismatches > $0.0001
  • Budget Enforcement: _pause_project_workflows() includes Phase 0 (DESIGN_WORKFLOW_DEFINITION_IDS), idempotent pause logic
  • OpenRouter Direct: _invoke_and_record() wraps all LLM call sites, extracts cost from response_metadata.token_usage.cost.total
  • Pi Extension: Real-time cost via turn_end hook, POSTs to /api/autopilot/cost-entries, TUI status display
  • Checkpoint by session_id: Survives agent retries without double-counting (NOT Agent.id)
  • 5 Rollup Levels: Task → Workflow → Feature → Design → Project
  • Security: Agent authentication on /cost-entries, rate limiting (60/min), path traversal protection, Pydantic validation
