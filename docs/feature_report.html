Key Implementation Details

  • Packaging only: the collector runtime (PiJsonlCollector, ClaudeCodeCollector, checkpointing, POST /cost-entries, the extension's TypeScript source) was already implemented and merged by prior features — this feature makes the already-written extension actually installable and correctly configured
  • One pi-detection branch: the install/build step lives inside the script's existing if command -v pi ... ; then block rather than a second top-level check, matching the script's existing style for CLI-presence detection
  • Always re-runs, no skip-gate: rm -rf/cp -r/npm install && npm run build run unconditionally on every install, which is what makes --update work with no special-case code
  • Graceful degradation: every failure path (npm missing, write failure, build failure) is a warn, not a fatal error — the JSONL-tailing fallback in cost_collection_service.py still collects the same cost data if the real-time extension can't be built
