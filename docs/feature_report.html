Summary

The design document assumed OpenCode ran one-shot with a capturable stdout JSON blob — that assumption was stale; OpenCode is launched as a persistent -i session with no deterministic session ID. scope_review authorized proceeding despite the design's own "stay deferred" gate. The shipped fix correlates a completed task to its OpenCode session row by directory + time window, then reads the row's pre-aggregated cost/tokens_* columns directly — no per-turn tailing needed.
